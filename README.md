# Movin' Artists Market — new design preview

This is a **preview of the new design**. It is not the live homepage.

Live site: [www.movinartistsmarket.com](https://www.movinartistsmarket.com)

- Search engines: this preview is served with `noindex, nofollow` and a `robots.txt` that disallows all crawlers.
- Flyer products: each **VIEW / BUY** button opens the live Wix product page.
- Plans: **Buy Now** opens the live pricing page.

To view locally: serve this folder with any static server (for example `python3 -m http.server`).

To publish as GitHub Pages: repo Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save. The preview URL will be:

https://movinartists.github.io/movinartists-market-preview/

Then paste that URL into `embed-snippet.html` on a hidden Wix Studio page (see the handover notes). Do not replace the live homepage until you are ready to launch.
